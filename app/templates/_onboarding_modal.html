Step 1 of 3

Connect an AI provider

Service Sentinel reads your containers' logs, release notes and compose files, and needs a model to make sense of them. Pick a provider and paste a key.

Any server speaking the OpenAI API. Point it at the server's /v1 base URL and name the model exactly as the server knows it.

Step 2 of 3

GitHub Optional

Release notes come from GitHub. Without a token you get 60 requests an hour, which a large stack can exhaust; with one, 5,000. A fine-grained token with no permissions at all is enough -- it only ever reads public repositories. Get one from github.com/settings/tokens.

Step 3 of 3

Set up access control

Service Sentinel has no login by default - anyone who can reach this address can use it. Set a username and password now, or explicitly turn this off if you're comfortable running without one (e.g. a private network you trust). You can change this later in Settings.
